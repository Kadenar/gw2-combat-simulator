# Quick start

## Run an included build

1. [Open the simulator](https://kadenar.github.io/gw2-combat-simulator/).
2. Choose a profession.
3. In **Workspace**, choose **+ New → Browse templates…** to open the **Build library**.
4. On **Standard Templates**, filter by role, boon, or specialization if needed.
5. Select a template to load its build and matching rotation into a new build tab.
6. Review the automatically calculated DPS beside the rotation.
7. Switch from **Workspace** to **Analysis** for the full breakdown.

The **•••** menu on a template can load only its build or only its rotation. Loading both is the safest default because
a rotation may depend on specific weapons, skills, traits, or profession mechanics.

## Make a simple comparison

1. Load a template as a baseline.
2. Note its DPS and warnings.
3. Change one build option or one rotation action.
4. Compare the new result with the baseline.

Change one variable at a time. Otherwise, the simulator can show that DPS changed but not which edit caused it.

## Save your work

- **Export** offers the current build alone or a combined **Build + rotation** JSON file.
- **Save Rotation** downloads the current rotation as JSON.
- **Import** and **Load Rotation** restore those files later.

Build changes are also stored locally in the browser. Export a complete setup before clearing browser data or moving to
another device.
