# Quick start

## Run an included build

1. [Open the simulator](https://kadenar.github.io/gw2-combat-simulator/).
2. Choose a profession.
3. In **Build templates**, filter by role, boon, or specialization if needed.
4. Select a template to load its build and matching rotation.
5. Review the automatically calculated DPS beside the rotation.
6. Switch from **Workspace** to **Analysis** for the full breakdown.

The **•••** menu on a template can load only its build or only its rotation. Loading both is the safest default because a
rotation may depend on specific weapons, skills, traits, or profession mechanics.

## Make a simple comparison

1. Load a template as a baseline.
2. Note its DPS and warnings.
3. Change one build option or one rotation action.
4. Compare the new result with the baseline.

Change one variable at a time. Otherwise, the simulator can show that DPS changed but not which edit caused it.

## Save your work

- **Export** downloads the current build as JSON.
- **Save Rotation** downloads the current rotation as JSON.
- **Import** and **Load Rotation** restore those files later.

Build changes are also stored locally in the browser. Export both files before clearing browser data or moving to another
device.
