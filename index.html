About this tool

A transparent rotation workbench

The simulator combines your equipment, upgrades, consumables, weapons, traits, skills, boons, and target settings into a browser-based PvE combat model. Queue skills in the rotation builder, then review the resulting timeline and damage breakdown.

It is intended for rotation analysis, implementation testing, and build comparison. Results are modeled estimates, not a replacement for in-game validation or benchmark logs.

What you can inspect

  • Build inputsGear, attributes, weapons, traits, and skills
  • Combat timingCasts, cooldowns, ammo, swaps, and interrupts
  • Damage outputExpected strike, condition, and contribution totals
  • Runtime stateBoons, target conditions, and profession resources

Technical details

How the simulator is built

01

Deterministic scheduling

A discrete event pipeline schedules casts, cooldowns, ammo, weapon swaps, profession actions, and deferred combat events on a millisecond timeline.

02

Expected-value resolution

Strike and condition damage are resolved from the configured attributes, target state, modifiers, and expected proc rates instead of random trials.

03

Shared platform, separate rules

Common Guild Wars 2 formulas and UI contracts are shared. Each profession owns its catalog, build rules, resources, mechanics, and simulation hooks.

04

Local-first application

The application runs in the browser without a build step. Profession pages keep independent local builds and support JSON import and export workflows.
