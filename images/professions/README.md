# Profession portraits

These 45 transparent PNGs cover the nine core professions and 36 elite specializations. The original set was downloaded
on September 7, 2026 from `https://optimizer.discretize.eu/images/professions/<name>.png`; selected portraits have since
been replaced.

The nine core portraits were replaced on October 17, 2026 using the following user-selected Guild Wars 2 Wiki artwork.
The built-in image generation tool adapted each source to the specialization portraits' painterly framing, colored wash,
and rough brush edges, with actual PNG alpha transparency. These are adapted images, not unmodified originals. Their
existing filenames keep them available to the loading screen's portrait rotation and the gear loadout background when no
elite specialization is selected.

Generation brief: preserve each source character's design, pose, equipment, and painterly rendering; reframe as a
centered waist/thigh-up portrait within a roughly round, dry-brush vignette on a square transparent canvas. Use
`mirage.png` and `holosmith.png` as framing and edge references only. Keep a profession-colored paint wash behind the
subject, remove the original paper or rectangular backdrop, and preserve translucent brush tips. No text, frame,
checkerboard texture, or extra characters or equipment. The palettes are gold/ochre for Warrior, amber/copper/brown for
Engineer, magenta/violet/mauve for Mesmer, blue/violet with warm elemental accents for Elementalist,
cyan/turquoise/steel blue for Guardian, spectral/moss green and charcoal for Necromancer, leaf/forest green for Ranger,
burgundy/crimson and charcoal for Thief, and charcoal/slate gray with restrained crimson for Revenant.
