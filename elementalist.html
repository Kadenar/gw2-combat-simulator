About this tool

This Elementalist tool is a fork of the original Elementalist Simulator.

This tool accurately simulates Elementalist DPS the same way the game calculates it. It doesn't use simplified formulas — it replays every combat event in order: weapon swings, skill casts, condition ticks, sigil procs, relic triggers, trait interactions, and attunement swaps.

  • Full build support — gear prefixes, runes, sigils, relics, food, utility, infusions, and all three traitlines with minor/major selections.
  • Accurate simulation — critical hits, condition stacking, boon tracking (Might, Fury, Alacrity, Quickness, etc.), and proc cooldowns are all modelled. Even handles Alacrity/Quickness loss mid-cast.
  • Expected values — no real RNG. Critical hit chance, weapon strength variance, and probabilistic procs use expected values, giving consistent, reproducible numbers.
  • Rotation builder — build your skill rotation manually and see the simulated DPS. Save and load entire builds (gear + traits + skills + rotation) as JSON.
  • Gear Optimizer — after building a rotation, run the optimizer to find the best gear combination (prefix mix, rune, sigil, relic, food, utility) for that exact rotation using coordinate descent.

Current limitations:

  • Skill list is intentionally incomplete — only DPS-relevant skills are included.
  • Lesser Elementals are not included.
  • Elite Elemental assumes Fire variant and automatically uses Flame Barrage. However, it does not deal increased damage based on Might that the player may grant it as part of their rotation.
  • No healing or barrier simulation.

If you spot any bugs or have any suggestions, please report them or contact me on Discord at Snappy Joe#8710.

Technical details
  • Modifier Contributions are calculated by running the simulation once, then re-running it with a specific modifier disabled (one run per modifier).
  • Cast times were manually gathered from .evtc logs and are treated as fixed values (even when in-game behavior can vary depending on skill chaining or aftercasts).
  • For DPS calculations, "start time" is the first hit event time, not the cast start time. "End time" is the end of the last cast event time (not hit time!) or the target death time, whichever is later.
  • Without Quickness, cast times are multiplied by 4/3 (hit times are also affected).
  • Instant-cast skills can be fired during another skill's cast window (Shift+click). This is handled by marking the instant-cast skill with an offset (in ms) from the start of the previous skill's cast window.
  • The tool supports interrupting skills. To do this, use Ctrl+click on the skill you want to interrupt (e.g. Scepter Air 2, Arc Lightning) and input interrupt time. The skill will produce all hits up until the interrupt time.
  • The tool supports precasting skills. Do to it, simply add "Combat Start" skill/icon to the rotation and mark it everything before it, as precast (you can, for example, precast Hurl, auras to trigger traits, Overloads, stack boons on yourself etc.).
  • Critical hits are calculated by incrementing the counter by the critical chance and checking if it exceeds 1. When it does, a critical hit is registered and the counter lowered by 1.
  • Skill details panel below the rotation shows total damage dealt, including condition ticks from this skill (unlike dps logs, which only show strike damage and aggregate each condition type).
  • Gear optimizer searches whole combinatory space of gear prefixes, runes, sigils, relics, food, utility, and infusions. It uses current rotation to evaluate each build, making it much heavier than other optimizers. It is advised to use optimizer with 1-2 prefixes selected, but multiple Sigils/Relics (accurate procs).
  • The tool supports importing dps.report links, however sometimes they may result in a "broken" rotation. If this happens, you need to manually fix it by editing the rotation file.
