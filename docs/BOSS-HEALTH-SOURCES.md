# Boss health: Elite Insights evidence

Collected 2026-10-23 from public reports hosted by [GW2 Wingman](https://gw2wingman.nevermindcreations.de).

The catalog contains 71 encounter/mode observations covering 43 encounters, including every raid-wing boss. Numbers are
exact EI target health fields. Wingman's rounded encounter metadata is never used for health.

## Source and interpretation

EI normally derives health from EVTC max-health events. The report's primary targets, difficulty, successful outcome, EI
encounter ID, and trigger ID are checked before importing. Sources are recorded in
[the manifest](../data/gw2/encounters/health-sources.json); generated data lives in
[health-data.ts](../js/games/gw2/app/boss-scenarios/health-data.ts). Each value retains the parser version and game
build.

Run `node scripts/data/update-boss-health.mjs` to re-read the reviewed reports, followed by Prettier on the generated
file. The updater aborts before writing if a source fails validation. Updating the source selection is a separate
review; older reports are observations of their recorded game build, not a guarantee of present-day health.

Multiple targets have separate totals. Xera, Deimos, and other targets with segmented or repeated health bars retain
EI's bar data; their total cannot be treated as a uniform 100%-to-0% pool. The preview defers percentage calculations
for these targets. Cross-checks compare exact primary-target totals and bars without averaging.

Harvest Temple normal-mode samples disagree on Soo-Won's health. The selected newer-game-build report is linked below;
the conflicting report remains recorded in the catalog. No guessed reconciliation is applied.

## Scope and event handling

- **Freezie and Cold War / Varinia Stormsounder:** excluded from the simulator at the user's request.
- **River of Souls:** event without a single boss health pool; no fabricated total is assigned.
- **Twisted Castle:** EI reports target health as -1 (not recorded). The UI has no selectable positive-health target.
- Some archived event reports are unavailable. Broken King and Eater of Souls use the full EI JSON endpoint.
- Difficulty modes without evidence never inherit normal-mode health.
